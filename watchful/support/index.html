A little help getting started

Make your first watcher.

  1. Open Settings and choose Gemini or OpenAI. Save your own API key. Saving alone does not run a check.
  2. Choose “Use … for checks” and review the data-sharing explanation. Provider limits and API charges are separate from Pro.
  3. For nearby searches, set a fallback town and country. Location permission is optional. Each watcher check may send available approximate location information or your saved fallback town to your selected AI provider, even when the watcher is not explicitly location-based.
  4. Create a watcher from a preset or your own instructions. Be specific about reliable sources and when you want a notification.
  5. Run it manually first. Open the result and sources before enabling automatic checks.

Common questions

Why did a check fail?

Check the selected provider, API key access and account limits. Gemini model availability differs by project. A connection test does not prove live web search works. There is no automatic paid fallback.

Why didn’t it run at the exact time?

Android and iOS control background execution. Timing is approximate and can be affected by connectivity, power-saving settings, permissions, force-stopping the app, and provider limits. Open the app and run manually if an update is time-sensitive.

How do car triggers work?

On Android, configure car connection inside a watcher. Choose automatic recognition of supported car names and Bluetooth car-audio devices, or select a specific paired device. On Android 12 and later, allow Nearby devices for this trigger.

On iPhone, include a watcher in car automation, then configure a personal Bluetooth or CarPlay automation in Shortcuts using “Run car watchers”. Where your iOS version offers the option, choose “Run Immediately” or disable “Ask Before Running” so the automation can run without additional confirmation.

Set a fallback town for checks without recent location. For location access while the app is in the background, review “Always” or “Allow all the time” in system settings where available. Allow notifications if you want system alerts. Permissions do not guarantee background execution, fresh location or notification delivery; Android and iOS control these behaviours.

What does Pro include?

The one-time purchase removes the two-active-watcher limit. It does not include AI usage. Open the Pro page and choose “Restore purchases”, using the same Apple or Google store account used for the purchase. Apple purchases do not transfer to Google Play or vice versa.

Where are my keys and history?

Keys use secure storage on this device. OpenAI history is saved locally. Gemini keeps only the latest result per watcher for the current app session, with no reuse or comparison across checks. When the app process closes, that result expires, including results referenced by an earlier notification. Run a new check after the cooldown if needed. Old Gemini test-build history is removed by this update. Remove keys in Settings and delete watchers to remove their stored history and check metadata. Removing a key here does not revoke it at the provider.
