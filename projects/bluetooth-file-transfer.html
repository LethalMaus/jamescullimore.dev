Bluetooth File Transfer

A BLE file-transfer proof of concept between Android and a laptop.

AndroidBluetooth LEDevice integration
Project links ↓

The project

The Android phone acts as a BLE peripheral with a GATT file-transfer service. A Python client on a laptop can exchange files with selected Android folders.

What it demonstrates

  • Upload and download files or folders over BLE.
  • Keep advertising and transfer state in an Android foreground service.
  • Use a Compose interface for permissions, folder selection, and transfer state.
