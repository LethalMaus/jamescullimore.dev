The project

A long-running collaboration across an Android app, Node.js backend and Vue.js web portal. The existing Java codebase needed continued development and a gradual move to Kotlin.

The contribution

  • Modernized and extended the Java application while migrating it to Kotlin.
  • Worked across the mobile app and surrounding web and backend stack.
  • Supported delivery through ongoing collaboration and technical guidance.
