The project

As a full-time mobile application developer at Hansgrohe Group, James worked on hansgrohe home and hansgrohe SmartExpert. The products connected homeowners and trained installers with digital water and shower systems. His core focus was Android, with contributions across iOS and backend integration.

The contribution

  • Developed Android applications using Kotlin and MVVM, including leading Android delivery for SmartExpert.
  • Integrated apps with connected devices, backend APIs and third-party services.
  • Implemented automated UI and unit tests and contributed code reviews and technical documentation.
