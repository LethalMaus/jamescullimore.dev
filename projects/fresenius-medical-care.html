Fresenius Medical Care

Dialysis UI applications built for a custom Android device.

Android / AOSPHealthcareAccessibility
Project links ↓

The brief

A custom AOSP-based device connected to a dialysis device needed a new set of applications. The user-facing interface had to present information from the clinic and device and guide users through device-related steps and status.

What we delivered

  • Held responsibility for three applications: the user-facing UI and supporting service apps.
  • Built the apps from scratch in collaboration with the design team.
  • Integrated accessibility, security, automated testing, and internationalization into the implementation.

The result

Three purpose-built Android applications, covering the user interface and supporting services, with accessibility and internationalization incorporated from the start. The work provides concrete experience of building Android software for a specialised healthcare device.
