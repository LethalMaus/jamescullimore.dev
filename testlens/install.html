Install TestLens for Jira

See what your tests actually prove.

TestLens connects acceptance criteria to reviewed assertions and execution evidence. Passing tests never automatically imply complete requirement coverage.

Open the Atlassian installer →

You need a Jira Cloud site and permission to install apps. The installer requests Jira read access and app storage. This evaluation app has no external backend. Optional evidence explanations use Atlassian Rovo.

Try the example

  1. Open TestLens in a Jira project’s app navigation, or add its issue panel.
  2. Select Explore the demo: passing authored sample results support zero verified criteria.
  3. Select Load recorded example: three real checks against a synthetic booking app support two of six criteria.
  4. Inspect the capacity gap, retry history, next-test recommendation and human mapping reviews.

Use synthetic data for evaluation. Read the privacy notice and evaluation terms.

This is a hackathon evaluation version. Uploaded JUnit is not authenticated CI evidence, and a verified criterion is not a release guarantee.
