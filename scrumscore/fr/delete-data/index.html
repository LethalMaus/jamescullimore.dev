Cette action supprime définitivement les profils, pronostics, participations et demandes de clubs du foyer. Elle concerne tous les joueurs de ce compte. Les groupes peuvent subsister pour les autres membres. Certains journaux administratifs limités et les sauvegardes peuvent avoir une conservation distincte.

Tu n’as plus accès à l’application ? Contacte l’assistance avec ton identifiant de compte si possible. Nous devons vérifier que le compte t’appartient avant de supprimer les données. N’envoie pas de données personnelles d’enfants.
